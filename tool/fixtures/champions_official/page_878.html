Regulation Set M-D Details

Eligible Pokémon

Regulation Set M-D sees even more Pokémon available to use in Ranked Battles, alongside Pokémon from Regulation Sets M-A through M-C.

Pokémon that will newly appear in Regulation Set M-D include the following.
• Heatran
• Dondozo
• Tatsugiri

Mechanics

Certain Pokémon can Mega Evolve if they’re holding a Mega Stone.

You can use Mega Evolution only one time per battle.

Mega Evolutions newly allowed under Regulation Set M-D include the following.
• Mega Heatran
• Mega Tatsugiri
