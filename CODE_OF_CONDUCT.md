# Code of Conduct / Código de conducta

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
([español](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)).
Below is a summary; the linked text is the one that applies.

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
Abajo hay un resumen; rige el texto enlazado.

## Our pledge / Nuestro compromiso

We want participation in this community to be a harassment-free experience for
everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

Queremos que participar en esta comunidad sea una experiencia libre de acoso
para todo el mundo, sin importar edad, cuerpo, discapacidad, etnia,
características sexuales, identidad y expresión de género, experiencia,
educación, situación socioeconómica, nacionalidad, apariencia, raza, religión
u orientación sexual.

## Expected behaviour / Comportamiento esperado

* Be respectful and patient, especially with newcomers. / Respeto y paciencia,
  sobre todo con quien empieza.
* Give and accept constructive feedback. / Críticas constructivas, dadas y
  recibidas.
* Respect other people's privacy: don't post someone else's saves, trainer
  names or IDs. / Respeta la privacidad: no publiques saves, nombres ni IDs de
  otras personas.

Not acceptable / No se acepta: harassment, insults, sexualized language or
imagery, personal or political attacks, publishing others' private
information, and requests for ROMs, keys or piracy. / acoso, insultos, lenguaje
o imágenes sexualizadas, ataques personales o políticos, publicar información
privada ajena y pedir ROMs, claves o piratería.

## Enforcement / Aplicación

Maintainers may remove comments, commits, issues or other contributions that
break this code, and may temporarily or permanently ban contributors. Report
incidents privately to the maintainers through GitHub (a private security
advisory in this repository, marked "Code of Conduct"). Reports are handled
confidentially.

Las personas que mantienen el proyecto pueden retirar comentarios, commits,
issues u otras contribuciones que incumplan este código y expulsar temporal o
permanentemente a quien lo haga. Informa en privado a través de GitHub (un
aviso de seguridad privado en este repositorio, indicando «Code of Conduct»).
Los avisos se tratan de forma confidencial.
